# Portfolio UI Kit

High-fidelity recreation of Agustina Müller's portfolio, driven by the same `colors_and_type.css` as the rest of the design system.

## Files
- `index.html` — the running kit (home → work → about → project → contact)
- `Components.jsx` — Button, Ast, Logo, Navbar, CategoryTag, IconPill, WorkCard, Footer
- `Pages.jsx` — HomePage, WorkPage, AboutPage, ProjectDetail + Hero, ExploreSection, StatsList, TagStrip

## Coverage
- Hero wordmark with outline mini-buttons + serif asterisk
- Bilingual copy (English UI, Spanish project descriptions)
- Marquee of IconPill categories
- Work cards (image + year + tags + title + description + `ver proyecto` CTA)
- Stats list (SERVICES / EXPERIENCE / INDUSTRY)
- Footer with email + LinkedIn
- Project detail view
- Contact splash

## Omitted
Mobile burger menu state (desktop-first recreation), live scroll animations (fade-ins), and the About page deep scroll — the Figma About frame is "en-progreso" (work-in-progress) so only a summary card is provided.
